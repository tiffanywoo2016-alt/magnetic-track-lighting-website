How to Specify Magnetic Track Lighting for 5 Commercial Project Types

By Tiffany Woo • June 5, 2026 • 5 min read

Specifying magnetic track lighting for a commercial project is different from selecting fixtures for a home. The track layout must account for ceiling type, control integration, load planning and the specific lighting needs of each zone — all within a budget that a developer or hotel owner will approve.

Here is a commercial track lighting specification guide for five common project types, with module recommendations and key specification points for each.

Quick Answer

Hotels and hospitality — specify DALI dimming, CRI 90+ modules, a mix of spot and grille modules. Track in corridors uses grille for anti-glare; lobby uses spot for accent.

Retail stores — high CRI 90+ spotlights with 15°–30° beam for product accent. Linear flood for wall displays. Zigbee or Casambi control for scene changes.

Galleries and museums — CRI 95+, R9 80+, spotlights 15°–24°. Track-mounted on independent circuits per wall for flexible re-lamping.

Offices and co-working — flood 60°–120° for general illumination. 0-10V or DALI dimming. Surface-mounted on concrete ceilings.

Restaurants and bars — warm 2700K–3000K spotlights for tables. Pendant adapters for decorative hang over bar counters. Casambi wireless for scene setting.

Hotels: A Hotel Lighting Specification Guide for Architects

Hotel projects typically have the most complex lighting requirements because different zones serve different functions on the same floor. A typical hotel lighting specification guide would recommend: grille modules in corridors for anti-glare (guests walk through looking up), spotlights in the lobby for accent on reception and artwork, and flood modules in function rooms for even ambient wash. Specify DALI dimming for centralised control.

Retail: Track Lighting for Product Displays

Retail lighting is about contrast — making the product stand out. Specify CRI 90+ spotlights with 15°–30° beam angles. For wall displays, add linear flood modules for a continuous clean wash. Wireless control (Casambi or Zigbee) allows store managers to change scene settings for different times of day or promotional displays.

Galleries: Precision Accent with High Colour Fidelity

Art galleries and museums demand the highest colour rendering — specify CRI 95+ with R9 80+. Use 15°–24° spotlights on independent circuits per wall so each zone can be re-lamped without affecting adjacent artwork. Track should be surface-mounted on visible ceiling for industrial-gallery aesthetic.

Offices: Even Illumination, Simple Control

Open-plan offices need even ambient light with no glare. Flood modules at 60°–120° are the primary choice. 0-10V dimming is cost-effective for zone-based control, or DALI if individual fixture addressing is required. Surface-mounted track is standard for concrete ceiling offices.

Restaurants: Warm Ambience, Flexible Zoning

Restaurant lighting must balance ambience with practical table illumination. Specify warm 2700K–3000K spotlights focused on each table (one spotlight per table zone). Pendant adapters add a decorative element over bar counters or centre islands. Casambi wireless control allows the owner to switch between lunch and dinner scenes from a tablet.

FAQ: Specifying Magnetic Track for Commercial Projects

How many modules can one track driver support?
This depends on the driver wattage and module power draw. A typical 150W 48V driver supports 8–12 standard spot modules. Always calculate total wattage before specifying the driver — a common mistake is under-specifying the driver, which causes modules at the end of the run to dim.
Can I use the same track profile for all five project types?
Yes. The 20mm track profile is compatible with all module types and can be surface-mounted, recessed or trimless. The track profile choice is independent of the project type — it depends on the ceiling structure and aesthetic preference.
