Complete System

Tracks, Modules, Drivers & Accessories, One Source

We supply every component in a 48V magnetic track system. No loose parts, no compatibility guessing.

Track Rails

20mm, 23mm and 35mm systems. Surface, recessed, trimless and pendant profiles. White, black, silver. Custom lengths available.

Light Modules

Spotlight, flood, grille, folding grille, linear, pendant, wall washer. 5W–35W, 3000K–6000K, CRI 80 / 90 / 95+.

Drivers & Control

48V constant-voltage drivers. ON/OFF, DALI 2.0, 0–10V, Triac, Tuya Zigbee, Casambi. Matched by total load.

Connectors

Straight, L-shape, T-shape, cross, flexible. Mechanical and conductive. End caps and mounting brackets included.

Power Feeds

End feed, middle feed, joiner feed. Positioned per layout to minimise voltage drop over long runs.

Accessories

Mounting clips, suspension cables, push-in connectors, dimmers, controllers, emergency backup options.

Compatibility

Driver Matching & System Compatibility

Not all 48V components are compatible. We confirm the entire system before quotation — track width, total wattage, driver capacity, power-feed position and control method.

✓ Total module wattage calculated against driver capacity with safety margin
✓ Power-feed position planned to avoid visible voltage drop
✓ Connector type and quantity confirmed for the layout
✓ Control protocol matched with driver and controller
✓ Installation method confirmed before track profile selection
Quality Levels

Standard vs Premium — Know What You're Paying For

We offer two quality tiers for selected product series. The difference is structural, not cosmetic.

Standard

  • ✓ Copper-clad aluminium conductor
  • ✓ Standard LED chips
  • ✓ CRI ≥ 80
  • ✓ Basic anti-glare (none / minimal)
  • ✓ Standard aluminium housing
  • ✓ Basic driver (non-dimmable or Triac)
  • ✓ Suitable: budget projects, residential

Commercial

  • ✓ Brass conductor pins & copper strip
  • ✓ SMD high-efficiency chips (Bridgelux / Epistar)
  • ✓ CRI ≥ 90, R9 > 50
  • ✓ Deep anti-glare (UGR < 19)
  • ✓ Reinforced aluminium body, better heat dissipation
  • ✓ DALI / 0–10V / Tuya-compatible driver
  • ✓ Suitable: hotels, retail, offices

Project-Grade

  • ✓ Full brass contacts + tinned copper strip
  • ✓ Premium chips (Osram / Lumileds / CREE)
  • ✓ CRI ≥ 95, full R1–R15 spectrum
  • ✓ Precision optics + micro anti-glare
  • ✓ Thick-wall extrusion, powder-coated finish
  • ✓ Programmable driver (DALI-2 / Casambi)
  • ✓ Suitable: luxury hospitality, designer projects
