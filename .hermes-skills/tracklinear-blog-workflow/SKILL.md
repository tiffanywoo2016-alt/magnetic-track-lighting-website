# Tracklinear Blog 写作发布流程

## 完整工作流
1. 我给大纲结构 → 用户调整确认
2. 我写完整文章 → 用户调整
3. 用户说【图片指令】我才出图（不在第1步出图）
4. 用户生成图片发我
5. 插入部署

## 开头方式策略（防审美疲劳）
每 2+ 篇切换一种开头方式：
- 数据驱动（"X% of buyers..."）
- 问题陈述（"Are you struggling with..."）
- 对比引入（"Surface vs Recessed: what's the difference?"）
- 客户故事（"A hotel in Lisbon..."）

## 写作规范
### B2B 扫读原则
- 60 秒看完（800 字内）
- 图文穿插（每 150-200 字插 1 图）
- 闭环结构：摘要 → 知识点 → 应用建议 → CTA
- 言之有物，用数据

### 格式要求
- Quick Answer 摘要框（适合 AI Overview 提取）
- H2 标题嵌入关键词
- Alt 标签 SEO/GEO/AIO 合规

## 部署流程
- 编辑 → git commit → git push → 验证
- GitHub Pages 托管，域名 tracklinear.com
