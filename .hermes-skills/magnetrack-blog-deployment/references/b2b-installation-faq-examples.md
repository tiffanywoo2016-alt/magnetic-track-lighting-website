# B2B Installation FAQ Examples (Blog 9)

These are user-validated B2B FAQ questions and answers about magnetic track lighting installation methods. Use as reference when writing FAQ sections for installation-related articles.

## FAQ Question Pattern

Each question must pass the **B2B Buyer Test**:
- Would an importer, contractor, lighting designer, or project manager ask this?
- Does it relate to cost, compatibility, installation feasibility, supply chain, or spec flexibility?
- ❌ NOT a C-end consumer question ("Is it safe?" "Can I install it myself?")

## Validated Q&A (Blog 9 — Installation Methods)

**Q: Does surface-mounted track lighting work on a concrete ceiling with no drop ceiling?**
A: Yes. Surface-mounted track lighting is designed for concrete ceilings, exposed beams and already-finished spaces. No drywall or suspended ceiling is needed. The track profile is fixed directly to the ceiling using mounting brackets.

**Q: Which installation method has the lowest labor and material cost?**
A: Surface-mounted has the lowest cost because it requires no ceiling preparation, no drywork coordination, and only one electrician. Recessed is moderate. Trimless is the most expensive due to higher labor skill requirements and additional finishing work.

**Q: Can the same track profile be used for recessed, trimless and surface installation?**
A: Not always. Some track profiles are designed for surface-mounted only. Recessed and trimless require profiles with compatible mounting brackets and trim accessories. Check with your supplier whether the track profile supports all three methods before ordering.

**Q: For a hotel project with multiple ceiling types, can we mix surface and recessed in different zones?**
A: Yes. Many hotel projects use recessed in guest rooms and corridors for a clean look, and surface-mounted in back-of-house areas, service corridors or concrete-ceiling zones. Using the same track system across zones keeps module compatibility and simplifies spare parts.
