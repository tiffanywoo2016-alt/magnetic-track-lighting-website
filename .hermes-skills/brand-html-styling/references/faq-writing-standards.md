# FAQ Writing Standards (Tracklinear B2B)

## When User is New to the Industry

If the user says "I'm new to the industry, I don't know what customers ask" — DO NOT write FAQs from your own general knowledge. Use this methodology:

### Research Pipeline

1. **Delegate 3-4 parallel search tasks** (one per product: 20mm, 23mm, 35mm, flood)
2. Each search task should target:
   - Google "People Also Ask" style queries for that product
   - Industry forum questions (Reddit r/LED, Electrical Contractor forums)
   - Competitor FAQ pages (WAC Lighting, Nora Lighting, Paulmann, Lutron)
   - Real B2B procurement conversations
3. Filter results for questions that are:
   - **Unique to that product** (e.g. 20mm → voltage drop is a real concern; 35mm → pendant weight capacity)
   - **Spec-driven** (B2B buyers ask specs, not "what's magnetic track lighting")
   - **Decision-relevant** (helps buyer choose between widths, modules, or suppliers)

### Topic Clusters by Product

### 20mm Track
- Voltage drop / max load per feed
- Brand interchangeability / module compatibility
- Dimming protocols (DALI, 0-10V, TRIAC)

### 23mm Track
- 20mm vs 23mm difference (load, application)
- Heavier fixture support capacity
- Best commercial project types

### 35mm Track
- Pendant light weight capacity
- 20/23mm module compatibility on 35mm
- Restaurant/lobby project suitability

### Flood Module
- Flood vs spot module difference
- Built-in vs external driver options
- Beam angle options by application
