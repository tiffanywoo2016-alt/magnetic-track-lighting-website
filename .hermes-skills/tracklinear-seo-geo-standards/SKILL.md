# Tracklinear SEO/GEO 标准与图片规范

## SEO/GEO 标准
- Alt 标签不重复，自然语言描述，嵌入关键词
- 结构化数据（JSON-LD Schema）
- 语义化 HTML 标签
- sitemap.xml + robots.txt
- Quick Answer 摘要框适合 AI Overview 提取

## 图片尺寸规范
- Banner: 1920×1080
- 系统展示：1200×900
- 安装方式：900×1200
- 卡片图标：800×450
- CSS 使用 `object-fit: contain`

## 图片处理
- 上传前压缩转 WebP，quality 85

## Google Search Console (GSC)
- 域名验证方式：阿里云 DNS 添加 TXT 记录
- 提交 sitemap：使用完整 URL（`https://tracklinear.com/sitemap.xml`）

## 灯具文生图指令注意事项
- 场景真实合理（spot 打画不用 flood）
- 光效一致，灯头方向对准光束
- 过室内设计师审美，假光效损信任
