# 每周经验笔记记录规则

## 核心原则
记录**可复用的经验**，不是流水账或 Agent 操作细节。

## 三个要点
- **做对了什么** — 具体决策和做法
- **为什么有效** — 根因分析
- **以后怎么复用** — 可重复执行的方法

## 格式
```
## 成功经验
[描述做什么 + 为什么有效 + 以后怎么做]

## 失败经验与教训
[描述什么错了 + 根因 + 以后怎么避免]

## 可复用 SOP
[可以直接套用的步骤]
```

## 存放位置
`outputs/Weekly-Lessons-YYYY-MM-DD.md`（Obsidian vault 中）
